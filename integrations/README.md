# Use CheapAIModel in your favorite tools

CheapAIModel is OpenAI-compatible, so it works in any app that lets you set a custom base URL.

**You always need the same three values:**

| Setting | Value |
| --- | --- |
| Base URL | `https://api.cheapaimodel.ai/v1` |
| API key | your CheapAIModel key |
| Model ID | any ID from `GET /v1/models` ([list](https://github.com/cheapaimodel/docs/blob/main/models.md)) |
